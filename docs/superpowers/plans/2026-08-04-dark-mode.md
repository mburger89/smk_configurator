# Dark Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the whole app dark-mode aware, following the macOS system appearance by default, with a persisted in-app Light/Dark/System override.

**Architecture:** `Chrome` (design tokens, `Sources/SMKConfigurator/Views/UIStyle.swift`) changes from a `static let` enum to a `struct` constructed from a `ColorScheme`, with every token becoming a light/dark computed pair. Every view struct that reads `Chrome` gets a local `chrome` instance derived from `@Environment(\.colorScheme)`. A new `AppearanceMode` enum on `EditorState` (persisted via `UserDefaults`, same pattern as `drawerHeight`/`showAdvanced`) drives a `.preferredColorScheme(_:)` override applied at the app root, with a `View ▸ Appearance` menu to change it.

**Tech Stack:** Swift 6 / SwiftCrossUI (`AppKitBackend`, macOS). No test framework changes — this codebase has no view-layer or `EditorState`-layer unit tests (see `Tests/SMKConfiguratorTests/`, which only covers pure model/protocol logic), so verification is `swift build` as a compile-checkpoint plus manual runtime checks, consistent with how the existing `drawerHeight`/`showAdvanced` persisted settings are verified.

## Global Constraints

- No new dependencies — everything needed (`@Environment(\.colorScheme)`, `.preferredColorScheme(_:)`, `.commands`/`CommandMenu`, `Toggle` as a menu item) already ships in the vendored SwiftCrossUI package.
- No backward-compatibility shims: `Chrome` fully changes from static enum to instance struct in one commit — no dual API, no deprecated aliases.
- No protocol/shared-default abstraction for the two-line `@Environment`/`chrome` boilerplate repeated per view struct — per the approved spec, 23 occurrences of two short lines doesn't justify one, and each struct's `@Environment` property must be a real stored property (property wrappers can't be injected via a protocol extension).
- Default `AppearanceMode` is `.system` (unset/fresh install).

---

## Note: one addition beyond the written spec

The spec (`docs/superpowers/specs/2026-08-04-dark-mode-design.md`) covers every `Chrome.*` token but doesn't mention five raw `Color.white`/`Color.black` backgrounds that exist *outside* `Chrome` in four view files (`DesignCellView.swift:19`, `DesignGridEditorView.swift:32,52,94`, `DeviceModeViews.swift:29`, `PaletteDrawerView.swift:27`) — these would stay hardcoded light-only if left alone, which contradicts the spec's stated goal ("make every view dark-mode aware"). Four of the five are genuine light surfaces (cell face, DSN header/footer bars, transport card, palette drawer background) that map directly onto the `Chrome.surface` token the spec already defines for exactly this purpose (`Color.white` in light, `#2C2C2E` in dark) — Task 1 converts those four to `chrome.surface`. The fifth (`DesignGridEditorView.swift:32`, the grid canvas backdrop) is deliberately black regardless of theme — a high-contrast backdrop for the editable cells, not a themed "surface" — so it's left as `Color.black`, called out explicitly in Task 1 so it isn't missed or converted by mistake.

```swift
import DefaultBackend
import SwiftCrossUI

@main
struct SMKConfiguratorApp: App {
    @State var editor = EditorState()

    var body: some Scene {
        WindowGroup("SMK Keymap Configurator") {
            ContentView()
                .environment(editor)
                .preferredColorScheme(editor.appearanceMode.colorScheme)
        }
        .defaultSize(width: 1440, height: 900)
        .commands {
            CommandMenu("View") {
                Menu("Appearance") {
                    ForEach(AppearanceMode.allCases) { mode in
                        Toggle(
                            mode.rawValue.capitalized,
                            isOn: Binding(
                                get: { editor.appearanceMode == mode },
                                set: { isOn in if isOn { editor.setAppearanceMode(mode) } }
                            )
                        )
                    }
                }
            }
        }
    }
}
```
